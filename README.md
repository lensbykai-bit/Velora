# VELORA

VELORA is a mobile-first photo and video marketplace demo with a dark premium pink/purple interface.

## Demo v1 features

- Home marketplace and category navigation
- Explore Photos / Videos
- Search
- Product details
- Wishlist
- Demo checkout flow
- Purchases library
- Order history
- Creator follow state
- Upload & Sell demo
- Seller Dashboard
- Earnings demo
- My Listings
- Edit Profile
- Notifications
- Settings
- Installable PWA / offline shell
- Android/iPhone safe-area friendly bottom navigation

## Demo data

This build is a front-end demo. Purchases, wishlist, orders, follows, profile, settings, and seller listings are stored locally in the browser using localStorage. No real payment, withdrawal, authentication, or server file upload is connected.

## Files

- `index.html` — app shell and navigation
- `styles.css` — base theme
- `nav.css` — mobile bottom navigation
- `ui-v2.css` — extended marketplace/dashboard UI
- `app.js` — demo app logic
- `manifest.json` — PWA metadata
- `sw.js` — service worker/offline cache
- `vercel.json` — Vercel static deployment config
